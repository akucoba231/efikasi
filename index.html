Manfaat Aplikasi

Panduan Penggunaan

  • Menu ini menampilkan seluruh daftar permainan edukasi PJOK yang tersedia.
  • Gunakan tombol Filter Level (Semua, Mudah, Sedang, Sulit) di bagian atas untuk menyaring daftar permainan sesuai tingkat kesulitan.
  • Ketuk salah satu kartu nama permainan untuk masuk ke halaman Detail Permainan.
  • Di dalam Detail Permainan:
    • Pemutar Video: Menampilkan peragaan tata cara permainan secara visual (jika tersedia).
    • Informasi Lengkap: Ketuk dropdown (Peraturan, Cara Bermain, Alat yang Dibutuhkan) untuk membaca panduan teks secara rinci.
    • Format Diskusi: Ketuk tombol hijau di bagian paling bawah untuk mengunduh lembar aktivitas dan diskusi.
  • Menu ini memuat informasi mengenai sasaran, latar belakang, dan capaian kompetensi dasar dari pembuatan aplikasi Efikasi PJOK ini.
  • Menu ini berisi rincian dampak positif penggunaan media pembelajaran ini.
  • Manfaat dikelompokkan menjadi tiga bagian: manfaat untuk Siswa, manfaat untuk Guru, dan manfaat bagi Sekolah.
  • Menu yang sedang Anda buka saat ini.
  • Berisi petunjuk dan tata cara penggunaan seluruh fitur yang ada di dalam aplikasi.
  • Menu ini direncanakan untuk mengatur konfigurasi aplikasi di masa mendatang.
  • Saat ini, halaman pengaturan masih dalam tahap persiapan.
  • Gunakan menu ini untuk menutup sesi dan kembali ke Splash Screen awal aplikasi.
  • Tindakan ini aman dan sistem akan meminta konfirmasi Anda terlebih dahulu sebelum benar-benar keluar.
